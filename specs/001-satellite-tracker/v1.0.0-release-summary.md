## 🏗️ Architecture

### Frontend Stack
- **React 19** - Latest stable with concurrent features
- **TypeScript 5.9** - Strict mode enabled
- **Vite 7** - Fast build and dev server
- **Tailwind CSS 4** - Utility-first styling with dark mode

### Libraries
- **MapLibre GL JS** - Interactive maps (no API key)
- **satellite.js** - SGP4 orbital propagation
- **react-map-gl** - React wrapper for MapLibre

### Data Sources
- **CelesTrak** - Public TLE data (no auth required)
- **Nominatim** - OpenStreetMap geocoding (no API key)

### Storage
- **localStorage** - Favorites, TLE cache, last satellite

### Testing
- **Vitest** - Unit and component tests
- **Playwright** - E2E tests across browsers
- **@testing-library/react** - Component testing utilities
